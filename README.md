# Management Systems

This repository is a collection of custom-built, full-stack Point of Sale (POS) and business management systems, developed for small and medium businesses.Each project lives in its own folder within this repository, fully self-contained with its own frontend, backend, and documentation.

## About

These systems are built around how each business actually operates,retail and wholesale sales, M-Pesa and cash payments, stock/inventory control, staff roles, and reporting,rather than generic off-the-shelf software. Each project is tailored to its client's specific workflow while sharing a consistent, reliable technology foundation.

## Projects
1.Wines and spirits Management System.
2.Laundry and Carwash Management System.

## Common Tech Stack

Each project in this repo generally follows the same stack, adapted as needed:

| Layer          | Technology |
|----------------|------------|
| Frontend       | React + Vite, Tailwind CSS |
| Backend        | Node.js + Express |
| Database       | PostgreSQL (via Prisma or Supabase, depending on project) |
| Authentication | JWT-based, hashed passwords |
| Hosting        | Frontend on Vercel · Backend on Render |
